01 / Start here

Quickstart

Use Python 3.10 or newer. The offline app uses only Python’s standard library: no package install, API key, network access, GPU, or model download is required.

  1. Clone or extract the project and open a terminal in the project root, where README.md, lab/, and corpus/ live.
  2. Start the local server:
python3 -m lab serve

Open http://127.0.0.1:8080. Stop with Ctrl-C. To use another port:

python3 -m lab serve --port 8081

Then open http://127.0.0.1:8081. The server binds to the loopback interface. Keep it local; public source code does not mean the app is deployed.

Try the same workflows in your terminal

python3 -m lab ask 'How do bounded agents restrict tools?'
python3 -m lab agent --task safety --budget 6
python3 -m lab evaluate
python3 -m lab replay
python3 -m unittest discover -s tests -v

02 / The system

Three workflows, one local lab

The browser calls local JSON endpoints. lab/server.py serves the dashboard and routes requests; lab/core.py implements retrieval, bounded orchestration, and stream measurement. lab/__main__.py exposes the CLI. The browser has no API-key entry or arbitrary endpoint field.

Retrieval

Bundled Markdown → overlapping chunks → local TF-IDF vectors → cosine search → original cited passages.

Agents

A fixed plan → search → coverage check → finish sequence. Sequential roles, a step budget, and a visible trace.

Serving

Browser: synthetic stream replay. CLI: optional requests to a separately provisioned compatible model server.

The real endpoint adapter is for serving benchmarks only. Configuring it does not enable LLM answers, neural embeddings, or model-driven agents in the demos.

The four sample documents in corpus/ are instructional fixtures covering agents, retrieval, serving, and operations. No external vector database is used.

03 / Follow the evidence

Retrieval and cited answers

Index loads UTF-8 .md files from corpus/. It splits them into 85-word chunks with a 15-word overlap, computes sparse TF-IDF vectors, and returns up to three chunks with positive cosine similarity.

  • TF-IDF is lexical. Matching depends on words in the corpus; synonyms and paraphrases may miss relevant evidence. This is not a neural embedding model.
  • The “answer” is extractive. Returned text is copied from source chunks, not synthesized by an LLM.
  • Citations identify chunks. For example, retrieval:1 points to a chunk from retrieval.md. IDs may change if the document changes.
  • Scores are similarity, not confidence. A small positive score is enough to return a passage. An unsupported question that shares vocabulary may still retrieve text.
  • No matches means abstention. The app gives a no-evidence message if no positive-scoring chunks are found. It does not yet verify that every question is answerable.

Use your own local documents

Add UTF-8 Markdown files to corpus/ and restart the server to rebuild its in-memory index. CLI commands rebuild on each invocation. There is no browser upload or persistent indexing service.

To build genuine generative RAG, a future change would need an embedding and/or generation adapter plus answer-quality evaluation. The existing benchmark adapter does not provide either.

04 / Stay within the boundary

Bounded agent workflow

run_agent runs one of three predefined tasks: retrieval explanation, tool-boundary audit, or serving checklist. A deterministic planner uses a fixed query; the researcher searches the corpus; the reviewer checks for expected terms; the final step returns cited evidence.

  • Successful runs use four steps. The allowed budget is an integer from 1 to 6.
  • A budget of 3 stops after review with budget_exhausted and no final answer. A budget of 1 allows only planning.
  • No evidence or missing expected terms produces check_failed.
  • Roles run sequentially. There are no parallel subagents, LLM decisions, dynamic replanning, or retries.
  • The only tools search the local corpus and check evidence. They cannot execute commands, change files, call network services, or modify infrastructure.
A passed term-coverage check does not prove that an answer is correct, relevant, or safe. The reviewer is a teaching fixture, not an independent model evaluation.

05 / Optional real execution

Connect a model-serving endpoint

Provision an OpenAI-compatible chat-completions server separately, such as vLLM on suitable hardware. This lab does not install vLLM, start a model, or download weights. Choose the exact model name advertised by your server.

python3 -m lab benchmark \
  --base-url http://127.0.0.1:8000/v1 \
  --model YOUR_SERVED_MODEL \
  --runs 3 --timeout 30

The example contains a local endpoint and a model-name placeholder. Replace them with your own configuration. For a typical vLLM server, the API root includes /v1; the adapter appends /chat/completions.

Authentication and data sent

If your endpoint requires authentication, provide LAB_API_KEY through your terminal environment or secret manager. Keep it out of source files, URLs, screenshots, and the browser. Never paste a real key into these docs. Use HTTPS for remote endpoints, especially when sending authentication; the CLI currently accepts HTTP as well. Redirects are refused.

Only this fixed public benchmark prompt is sent:

Explain retrieval augmented generation in three short sentences.

The adapter does not send the document corpus, retrieved passages, or browser questions. It requests at most 128 output tokens and asks for streamed usage with stream_options.include_usage. Some compatible servers reject that option.

Run boundaries

The CLI permits 1–10 sequential requests and a timeout of 1–120 seconds. Each response has a size limit. There is no warmup or automatic retry. The timeout is applied to socket operations and checked between lines; a blocked read can extend the total elapsed time by up to another socket timeout. Failures are recorded by exception type and cause a nonzero CLI exit.

06 / Interpret the numbers

Evaluation and serving metrics

Retrieval evaluation

evaluate runs four labeled sample questions. Document hit rate @ 3 is the fraction whose expected document appears among the top three retrieved chunks. A 100% score means 4/4 fixture questions found their expected document. It does not measure answer correctness, citation support, or real-world performance. These examples are not a held-out test set.

Streaming measurements

TTFT / time to first content
Elapsed client time from request start to the first nonempty content delta. Includes request and network overhead. Role-only events are ignored.
Mean inter-content-event latency
Average spacing between nonempty content events. One event can contain several tokens, so this is not true token-level inter-token latency (ITL). A single content event has no interval.
Output tokens per second
Server-reported completion tokens divided by total response duration. If a positive integer token count is missing, throughput is unavailable; it is never estimated from characters. This is not decode-only speed or aggregate server throughput.
Synthetic replay
Five delayed local content events exercise the instrumentation. Timings reflect fixture delays and local scheduling, not a model. Replay supplies no token count, so token throughput stays unavailable.

The real adapter returns individual sequential runs. It does not calculate latency percentiles, run concurrent load, or test server saturation. No real GPU or model benchmark results are bundled. Truncated streams, empty output, and provider stream errors are not counted as successful benchmark results.

07 / Get unstuck

Troubleshooting

“No module named lab”
Run commands from the project root containing lab/, not inside the lab/ directory. Check Python with python3 --version.
Port is already in use
Stop your earlier lab with Ctrl-C or choose python3 -m lab serve --port 8081. Open the matching URL.
The page loads but requests fail
Keep the server terminal running and use http://127.0.0.1:PORT. The browser’s POST origin must match this exact host and port. Opening the HTML file directly or using localhost can fail.
No evidence, or unrelated passages
Check the Markdown files in corpus/, use vocabulary that appears in them, and restart after edits. Positive similarity does not guarantee the passage answers the question.
The agent stops without an answer
A budget below four cannot finish the fixed workflow. Use six to allow completion. A failed coverage check needs relevant evidence; adding more steps does not repair missing evidence.
Real endpoint requests fail
Check that your separately provisioned server is reachable, the API root matches your server (typically including /v1), the model name matches, and any required LAB_API_KEY is set in the CLI environment. Confirm support for streamed chat completions and the usage option. Check server logs privately; do not publish credentials.
Throughput shows “Unavailable”
This is expected for synthetic replay or a real endpoint that omits completion-token usage. It is not a zero-throughput result.
Tests cannot bind local sockets
HTTP integration tests open loopback test servers. Run them in an environment that permits localhost sockets. Do not disable system security controls to run this demo.

Before exposing this beyond your machine

The bundled HTTP server has no login, rate limiting, or multi-user isolation. Origin checks are not authentication. Keep it local; a hosted version would need appropriate authentication, transport protection, bounded requests, and a production server. Keep retrieved text untrusted if you later add a real model or new tools.
